# java-calculator-precourse

## 기능 :
    사용자가 입력한 문자열에서 숫자만을 추출해 덧샘하는 덧샘기
    특정한 구분자(, :)로 숫자를 구분하고, 사용자가 임의로 구분자를 한 개 지정할 수 있다.
    양수만 덧샘 가능하다
    정확한 실수 표현을 위해 BigDecimal 사용

## 잘못된 입력으로 취급되는 예시 :
    1. 커스텀 구분자 포멧을 지키지 않은 경우    /;\n1;2;3
    2. 커스텀 구분자를 여러개 지정한 경우      //;\n//!\n1;2!3 or //!!\n1!!2!!3
    3. 실수도 취급하므로 .을 커스텀 구분자로 지정한 경우     //.\n
    4. 입력의 맨 앞과 맨 뒤가 구분자로 끝나는 경우 ,1,2,3 or 1,2,3,
    5. 연속된 구분자를 썻을 경우   1..2.3
    6. 마이너스 값을 입력한 경우 (단, //-\n1-2-3 은 가능)
    7. 구분자로 등록되지 않은 문자를 입력한 경우  1;2;3
